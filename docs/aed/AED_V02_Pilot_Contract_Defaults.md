# Pilot Contract Defaults v0.2 — initial version 1

Authority: owner master prompt of 2026-10-15 explicitly authorizes defining uncalibrated semantics for the pilot. These defaults are **not production-approved**. A–G numeric tables and Fixed baseline remain unchanged. Protocol identity: `AED_V02_PILOT_OPPORTUNITIES_1`. Missing/old protocol is partial, never implicitly Verified. Test-only inputs are excluded from production learning.

## Resolved opportunities / historical competence

An encounter opportunity requires >=5 observed seconds with a real threat/target/episode, complete authoritative census, and no sequence gap. Down is a failure only with the same player and causal threat episode; returning to PATROL/SEARCH (Stalker) or IDLE/FLEE/DYING (Minion), with the victim Alive and >=10 observed threat-free seconds, resolves survival success. A phase cut, disconnect, debug operation, missing entity without despawn, missing onset or source gap censors it. Merely ending an upload does not resolve success. Minimum qualifying long Chase: 20 continuous authoritative CHASE seconds; proactive Seek against that player pauses 15 seconds after resolution, without suppressing legitimate fresh perception.

The existing proactive Seek planner consumes anonymous room heat, not player identities. The pilot conservatively pauses that proactive planner for the same 15 seconds after a qualifying Chase, so it cannot reselect the recovering player through room heat. Fresh LOS/noise/combat remains active. Fixed has no such pause; this is an explicitly recorded pilot scope of the recovery rule.

History uses only independently reconstructed opportunities from ended, comparable pilot matches (same policy/opportunity version, scene fingerprint, mode/difficulty and roster size). Match-balanced success fraction [0,1], 14-day half-life, maximum age 30 days; >=3 distinct matches and >=8 resolved opportunities per relevant axis, <=25% censored eligible samples. Unknown members block increases. Weakest eligible member must score >=.65; team mean never substitutes for a member/axis. Resource/Objective/Tool/Teamwork dimensions require their own resolved causal outcomes; encounter survival is not relabeled as those skills. RiskStyle remains descriptive.

## Closed Resource and Objective opportunity families

Resource need is established by an actual Down needing revive, or an authoritative Minion tool relocation losing a specific tool type. The latter expires after 30 seconds, recovery or phase end. It covers each of the five types through actual loss, not empty inventory or an unsolicited client request. Check all usable inventory, charges, recoverable world supply, monster custody and living helpers' door-aware paths. One scarcity window per causal loss/revive episode, at least 5 seconds continuously unavailable; retries do not create new windows. Other exploration/use preferences create no eligible need under this pilot contract; they are not failures.

Objective opportunity is an actual authoritative operator/core-carry unit observed before a causal impact. Interruption requires an accepted impact at the action source (Down, Minion slow, forced Core drop or tool relocation), matching actor/victim/unit/tick and independently reconstructed world consequence. Blocked seconds count only while that impact actually prevents the operation (Down/caught/slow or unresolved forced carrier loss), bounded by resume, unit completion, threat ending, phase or disconnect. A threat nearby, generic slow progress, AFK, puzzle learning or voluntary exit is not causal proof. Overlapping impact intervals merge per unit/player; resumption by another player terminates the old blocked interval and never grants the old operator a fictitious completion.

## Team pressure

PP still uses approved five-channel .30/.20/.25/.15/.10 weights and the approved normalization/window/decay/hysteresis. Team severity is the maximum of: .6*worst PP + .4*mean PP; Down/Eliminated roster fraction; mean verified objective-blocked component; fraction of players simultaneously targeted by Stalker and Minion. Any PP3/PP4 forces severity >=.65. Team tier is reversed (`TP=4-PP-tier(severity)`), with a separate Unknown result if any member/channel is missing/stale. This is not an equivalence between the legacy Quiet enum and TP. Historical weakest protection is an additional increase gate, never a pressure score proxy.

## Resources / support

R0 retains the existing planner. R-1 selects reachable side-room points, preserving required types. R1 selects points on the first/mandatory route; R2 prefers shortest entry path; R3 selects the shortest safe entry/mandatory route outside actor/objective bodies. Roles must be registered in the scene manifest; use actual NavMesh path distance and door state, never invented meter cutoffs. Grades affect only future reservations; existing items remain immutable.

Ordinary support: one item per transaction, maximum two/match, 90-second separation, actual unresolved need-to-type mapping above, no usable reachable alternative. Emergency: one/match, FirstAid for a real Down with no reachable revive capacity. A Down is allowed for this relief action only; all live threats must still be safe, no caught/revive/mission critical interaction, and a living helper needs a validated route. No support spawn inside an actor, Safe Room threat volume, locked route or objective body. Support is a separate approved action with immutable action ID, spawn instance/marker, real lifecycle receipt and later world proof; changing a grade is not a claim to have spawned support.

All increases retain 180-second pacing separation and require a new complete observation window; ordinary relief uses 90 seconds. Zone3 increase additionally requires 30 seconds since actual Zone3 entry, FIND_FRIGATE, verified actual census and a free positive axis. No final-phase increase. Separate handoff transactions must observe the previous effect reverting before granting another positive axis.
# Implementation additions (same pilot authorization)

- Rev02 explicitly permits current-evidence relief for ColdStart players. A current roster snapshot whose only PARTIAL reasons are `PROFILE_MISSING` / `INSUFFICIENT_OBSERVED_PROFILE_EVIDENCE` may stage the neutral envelope. In-match relief additionally requires complete independent current pressure, except the independently verified emergency need path. The snapshot stays PARTIAL; no history is synthesized. Invalid, stale, mixed-reason or adverse proposals remain blocked.
- Core objective competence requires an actual accepted pickup, at least five observed carry seconds and an accepted placement of that same core by that operator. A direct verified Stalker Down / Minion forced drop can resolve failure; voluntary drops and cut observation are censored. Repeated windows identify the same pickup, rather than adding samples.
- Teamwork competence uses an observed authoritative revive attempt with a named, alive helper (at least one observed second), then the accepted revive of that victim by that helper. Elimination during the observed attempt resolves failure; cancellation, another helper and missing resolution are censored. Each Down/helper pair is counted once.
- General Tool competence remains unsupported by the current resolved-outcome producers. Counts of uses, carrying an item, or successful unrelated chases do not establish effective use of all five types. Optional-supply reductions and R-1 therefore cannot obtain a `Tool` increase entitlement from legacy rows. Completing effect-specific Tool outcomes remains an implementation requirement.
- Emergency source windows may begin after five actual observed seconds. This does not make PP/TP complete before the normal thirty-second minimum. Support still requires a canonical Down, independently unavailable reachable usable FAK capacity, an alive helper and a safe route/window.
- A committed action has sixty simulation seconds to produce its actual effect before reconciliation records `FAILED_EFFECT`. A committed revision is retained; it is never relabeled APPLIED or silently rolled back. Pending abort delivery remains a lifecycle reconciliation requirement.
- Placement search is bounded to 4,096 candidate visits to avoid blocking the Host on an impossible authored layout. Exhaustion produces Hold; it never relaxes required types, spacing, role or route checks.
- Core-drop objective interruption lasts only while the actual causing Minion still targets that player in TRACK/HARASS (or a separately observed Down/Caught/Slow prevents progress). Another operator, resumption or threat release stops the interval.
- Threat-free resolution checks the victim's actual life/caught/slow state and all targeted active Stalker/Minion states. Switching episode, detection without a new chase, or being caught cannot certify survival success. A verified Minion Slow/CoreDrop/ToolLoss during an eligible encounter resolves failure; mere proximity or an unrelated Down does not.
- Historical matches require a clear accepted end-of-capture seal and no gameplay disconnect, abort, debug or invalid inventory lineage. Reconnection does not erase the historical exclusion. Missing seal or malformed stored evidence is Unknown/Insufficient; baseline match closure never waits on this learning-only seal.
- First Aid Tool outcomes require a named actual revive attempt, usable held kit, independently reachable victim and a same-instance consume joined to that helper's accepted kit revive. General Tool competence requires each of the five families to meet the three-match/eight-resolved/25%-censored limits independently; its score is the weakest family. First Aid alone cannot qualify the other four missing producers. This is an implementation limit, not a flag to bypass.
